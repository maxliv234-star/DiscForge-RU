# UDF 2.50 ISO verification scope

A Blu-ray ISO must be checked for UDF 2.50 metadata before being called ready for burning. This is separate from the existing BDMV directory checks. A header check alone cannot prove disc playback, BD-J menu behavior, or correct file-tree contents.

Target formats: Full HD BD25 and BD50 only. UHD, 4K, BDXL and DRM bypass remain out of scope.
