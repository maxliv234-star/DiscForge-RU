# DiscForge RU — macOS (первый этап)

## Возможности и ограничения

- Общий с Windows GUI на PySide6: импорт, анализ, конвертация видео в BD-ориентированный формат и подготовка структуры Blu-ray через tsMuxer.
- Отдельный безопасный **терминальный модуль записи готового ISO** — `macos_burn.py`, использует штатный `hdiutil burn`. В команде включены верификация записи и закрытие диска; параметрами отключается синтез файловой системы и изменение исходных блоков.
- **Не сделано:** запись из GUI одним нажатием, авторинг интерактивного меню, подтверждённая совместимость с плеерами, сертификация UDF 2.50, готовое приложение с цифровой подписью.
- **Важно:** размер и расширение ISO не доказывают соответствие Blu-ray/UDF 2.50. Сначала проверяйте на BD-RE и конкретном плеере.

## Mac с процессором Apple Silicon

1. Установите Python 3.11+ и FFmpeg (например, `brew install ffmpeg`).
2. Установите совместимый tsMuxer для macOS отдельно, указав абсолютный путь, если необходимо.
3. Выполните `bash start_macos.command` для GUI. Если бинарники Homebrew не видны из приложения, укажите их пути в настройках.
4. Привод ASUS BW-16D1HT — внутренний SATA 5.25\". Для подключения к Mac требуется **корпус или SATA–USB адаптер для 5.25\" оптических приводов с внешним питанием 12 В**. Переходника без питания недостаточно.
5. Запись из терминала (после создания ISO):

```bash
python3 macos_burn.py drives
python3 macos_burn.py burn "/путь/к/фильму.iso" --dry-run
python3 macos_burn.py burn "/путь/к/фильму.iso" --speed 2 --yes
```

Для выбора одного из нескольких приводов используйте `--device` с идентификатором из `hdiutil burn -list`.

`--dry-run` не обращается к приводу. Настоящая команда `burn` требует `--yes`, при этом macOS может дополнительно запросить вставить диск. В случае успеха утилита сообщает об успешной записи/проверке, но **это не подтверждает совместимость с бытовым плеером**.

## Сборка приложения

```bash
bash build_app_macos.sh
```

Результат: `dist/DiscForge-RU.app`. Это **неподписанная** сборка; выпуск подписанного/notarized приложения отдельный этап. В GitHub Actions настроена аналогичная экспериментальная сборка.

Используем отдельную ветку для macOS и PR в общий репозиторий DiscForge RU. Windows и macOS сохраняют общее ядро.
