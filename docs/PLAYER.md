# DiscForge Player — Blu-ray-проигрыватель для ПК (0.1 alpha)

Отдельное приложение в репозитории DiscForge RU. Оно воспроизводит фильмы через LibVLC на компьютере с ASUS BW-16D1HT. Для просмотра на ТВ подключите компьютер к телевизору через HDMI.

## Запуск Windows/macOS
1. Установите Python 3.11+, VLC 3.x (архитектура VLC должна совпадать с Python).
2. Выполните: python -m pip install -r requirements-player.txt
3. Выполните: python -m player.app
4. Выберите Дисковод (например D: на Windows), папку BDMV либо видео/ISO.

## Функции
Воспроизведение Blu-ray, BDMV, ISO и видео; пауза, главы, звук, субтитры и навигация меню.

## Ограничения
Это alpha без реального теста на ASUS. Поддержка BD-J зависит от VLC/libbluray/Java; ISO с меню может не работать. Программа предназначена для собственных незащищённых дисков и не обходит DRM. На macOS внутренний SATA-привод ASUS требует внешнего USB–SATA корпуса с отдельным питанием. Компьютерное воспроизведение не подтверждает совместимость с бытовыми плеерами. Подключение привода к PS5 Digital таким способом не работает.
