# Full HD Blu-ray ISO — проверка метаданных UDF 2.50

До публикации сгенерированного ISO (BD25 или BD50) DiscForge RU выполняет предварительный анализ:

- Размер образа в пределах ёмкости BD25/BD50, выравнивание на блок 2048 байт.
- Последовательность распознавания BEA01 / NSR03 / TEA01.
- Основная или резервная точка привязки UDF (AVDP) и ограниченные Main/Reserve VDS.
- Контрольные суммы тегов и CRC-16 проверяемых дескрипторов.
- Logical Volume Descriptor: размер блока 2048 и UDF 2.50 (ревизия 0x0250).

Команда для отдельной проверки:

```sh
python -m tools.iso_udf_preflight /path/to/movie.iso --profile BD25
```

Код завершения 0: пройдены **только проверки метаданных**; 2: есть ошибки.
Вывод JSON содержит ошибки и предупреждения.

**Не является доказательством пригодности диска для бытового плеера.**
Модуль не проверяет UDF partition maps, дерево каталогов внутри ISO, наличие и
валидность BDMV/CLPI/MPLS/M2TS в образе, настоящие интерактивные BD-J/HDMV
меню, работу глав/звука/субтитров или результат записи на ASUS BW-16D1HT.
Для этого нужны отдельные проверки и физический тест с BD-RE и плеером.

Поддерживаются только Full HD 1080p, BD25 и BD50. UHD/4K/BDXL отложены.

При повреждении основной последовательности Main VDS проверка пытается
использовать корректную резервную Reserve VDS и добавляет предупреждение.
Это проверка метаданных, а не доказательство целостности файлов ISO.
