# DiscForge TV — Android TV / Google TV

Ранний MVP с открытым исходным кодом. Предназначен для домашней сети и не требует Plex/Jellyfin.

## Что реально реализовано

- Отдельное нативное Android TV приложение на Kotlin/Media3 ExoPlayer с интерфейсом для пульта.
- Подключение по локальной сети к серверу на Windows/macOS, каталог видео и воспроизведение MP4/MKV.
- HTTP Range для перемотки, выбор аудиодорожек/субтитров посредством стандартных элементов Media3, если присутствуют в файле и поддерживаются Android TV.
- Сервер с кодом подключения (X-DiscForge-Token), приватная папка библиотеки и ограничение соединений ТВ-клиента локальными IPv4-адресами.

**Пока не реализовано:** прямое считывание физических Blu-ray с ASUS BW-16D1HT, передача исходной структуры BDMV/BD-J меню на телевизор, управление дисковыми меню с пульта телевизора, транскодирование для неподдерживаемых кодеков. Не называем этот MVP готовой заменой домашнего Blu-ray-плеера.

## 1. Запуск сервера на ПК

Подготовьте папку с собственными MP4/MKV файлами. Требуется Python 3.11+ (внешние пакеты не нужны).

Windows:

    py -3 -m tv_server --media-root "D:\Movies" --host 0.0.0.0 --port 8098

macOS:

    python3 -m tv_server --media-root "$HOME/Movies" --host 0.0.0.0 --port 8098

В терминале появится **код подключения**. Он сохраняется в ~/.discforge-tv/token для повторных запусков. Найдите локальный IP компьютера (например 192.168.1.30). Компьютер и Xiaomi TV должны быть в одной сети. Windows Firewall может запросить разрешение для частной сети.

**Безопасность:** сервер использует обычный HTTP с секретом в заголовке и подходит только для доверенной домашней сети. Не настраивайте перенаправление порта 8098 в интернет! По умолчанию без `--host 0.0.0.0` сервер принимает только локальные подключения. Для общего Wi-Fi понадобится HTTPS/туннель на более позднем этапе.

## 2. Установка на Xiaomi Android TV / Google TV

Загрузите APK из успешной GitHub Actions сборки `DiscForge TV Android` (Artifacts → DiscForge-TV-Android-debug-unsigned). На телевизоре разрешите установку APK из выбранного источника. Установите приложение любым удобным способом: через ADB или передайте APK на телевизор локально. Запустите **DiscForge TV**, введите IP:8098 и код из терминала ПК, нажмите «Подключиться». Выберите фильм пультом.

Если телевизор не использует Android TV / Google TV, этот APK не установится — понадобится другая клиентская платформа. Модель Xiaomi 55” 144 Гц пока не подтверждает конкретную ОС.

## 3. Локальная сборка APK

Требуется Android SDK 35, JDK 17 и Gradle 8.9:

    cd tv/android
    gradle testDebugUnitTest assembleDebug

Результат: `tv/android/app/build/outputs/apk/debug/app-debug.apk`.

## Дальнейшее развитие

Проверка реального Xiaomi TV и поддерживаемых кодеков, автоматическое обнаружение сервера, транскодирование HLS при необходимости, экран постеров, несколько аудио/субтитров, журнал ошибок, безопасная передача без открытого HTTP и связка DiscForge Player с физическим Blu-ray через ПК. Воспроизведение видео по сети нельзя выдавать за воспроизведение полноценного интерактивного BD-J меню.
