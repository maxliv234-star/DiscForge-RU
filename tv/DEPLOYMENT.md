# DiscForge TV — запуск без Терминала и Synology NAS

## Автозапуск сервера на Mac

Остановите предыдущий интерактивный `python3 -m tv_server` (Ctrl+C), чтобы освободить порт 8098.
На Mac с установленным Python 3.11+ из корня клонированного репозитория:

```bash
bash tv/macos/install_launchagent.sh "$HOME/Movies/DiscForge"
```

macOS запустит службу при входе пользователя. Терминал можно закрыть, но **Mac должен быть включён и не спать**. Код пары остаётся в `~/.discforge-tv/token`. Посмотреть его на собственном Mac: `cat ~/.discforge-tv/token`. Не публикуйте этот код и не открывайте порт в интернет.

Проверка: `lsof -nP -iTCP:8098 -sTCP:LISTEN`. Остановка: `launchctl bootout gui/$(id -u) "$HOME/Library/LaunchAgents/ru.discforge.tv.server.plist"`.

## Synology DS225+ без включённого Mac

На DSM установите **Container Manager**, если он доступен для текущей версии DSM. Создайте общую папку с видео и отдельную папку конфигурации (например `/volume1/docker/discforge-tv`). Предоставьте UID 10001 права **чтения** на папку видео и **записи** на папку конфигурации. Имя тома /volume1 — лишь пример, проверьте фактические пути.

Скопируйте содержимое репозитория на NAS, зайдите в `tv/docker`, скопируйте `.env.example` в `.env` и впишите реальные пути из DSM. В Container Manager импортируйте `compose.yaml` как проект либо запустите:

```bash
cd tv/docker
cp .env.example .env
# Отредактируйте .env, затем:
docker compose up -d --build
```

Сервер слушает **TCP 8098**, обнаружение в LAN — **UDP 8099**. На роутере **не** открывайте эти порты в интернет. Сохранённый секрет на NAS — файл `/volume1/docker/discforge-tv/token` (фактическое расположение зависит от .env). Для первого сопряжения введите IP NAS:8098 и этот токен на TV. Далее приложение сохраняет пару и пробует подключиться автоматически.

## Постеры и категории

Категория — имя первого подпапочного каталога. Например `/media/Сериалы/Название/Эпизод.mkv` будет показан в категории «Сериалы». Постер берётся **локально**: `Название.jpg` рядом с `Название.mkv`, либо `folder.jpg` в папке. Поддерживаются PNG; изображения больше 8 МБ не выдаются. Никаких обращений к внешним каталогам и передачи названий фильмов в интернет нет.

## Важное

Память просмотра хранится локально в приложении. Первое сопряжение выполняется вручную; UDP-поиск не передаёт секрет, а использует сохранённый код и проверку HTTP. Не подключайте TV к недоверенной сети: HTTP с токеном **не шифрован**. Для перехода с Mac на NAS потребуется **один раз** ввести код новой службы; автоматическая миграция секретов не выполняется.
