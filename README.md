# DiscForge RU 💿

**Open-source Blu-ray authoring studio for Windows and macOS — alpha 0.1.0.** Русскоязычный интерфейс. Отдельный проект, не связанный с PdfCraft.

> **Принцип проекта:** результат должен открываться на бытовом Blu-ray-проигрывателе с настоящим меню, выбором глав, дорожек и субтитров. **Эта функциональность пока не готова!** Альфа 0.1 создаёт тестовые BDMV/ISO **без интерактивного меню**. Не записывайте дорогие BD-R, пока не проверите выход на BD-RE и конкретном проигрывателе.

## macOS (Apple Silicon / Intel)\n\n**macOS поддержка экспериментальная.** Для запуска GUI используйте `bash start_macos.command`; запись существующего ISO из терминала доступна через `macos_burn.py`. См. [документацию macOS](docs/MACOS.md). Отдельная сборка неподписанного `.app` предусмотрена в macOS CI. Совместимость с бытовыми плеерами и UDF 2.50 ещё не подтверждена.\n\n## Установка (Windows 10/11)

1. Установите **Python 3.11+** и отметьте добавление Python в PATH.
2. Распакуйте проект, запустите `start_windows.bat`. Он создаст `.venv`, установит PySide6 и откроет программу.
3. Установите независимо от этого проекта **FFmpeg** (`ffmpeg.exe`, `ffprobe.exe`) и **tsMuxer** (`tsMuxeR.exe`). В программе укажите полные пути, если они не доступны в PATH. Не запускайте программы из ненадёжных архивов.
4. Добавьте небольшой тестовый видеофайл, перейдите на вкладку **Главы**, расставьте точки перехода. В параметрах оставьте профиль BD25 и кодер **CPU x264**.
5. Нажмите **Создать Blu-ray**. Для больших файлов кодирование требует много времени и свободного места. Результат будет в выбранной папке.
6. Проверьте результат программным проигрывателем с поддержкой Blu-ray и затем **перезаписываемой** болванкой BD-RE на вашем плеере. В этой версии НЕТ меню, хотя список глав уже передаётся tsMuxer.

### Ручной запуск

```powershell
py -3 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe main.py
```

### Сборка EXE (Windows)

```powershell
build_exe_windows.bat
```

После сборки смотрите `dist\DiscForge_RU\DiscForge_RU.exe`. Внешние FFmpeg и tsMuxer не включены в дистрибутив и требуют отдельной установки. Не переносите бинарники без соблюдения их лицензий.

## Режим командной строки (без GUI)

```powershell
py -3 cli.py probe "C:\Video\movie.mkv"
py -3 cli.py build "C:\Video\movie.mkv" --profile BD25 --output "D:\BluRay" --chapter 00:10:00 --chapter 00:30:00
```

CLI и GUI создают только Blu-ray **без дискового меню**.

## Архитектура

- `main.py` — графический интерфейс, QThread для анализа и очереди, редактор глав, проект.
- `cli.py` — командный интерфейс, работает без PySide6.
- `core.py` — `ffprobe → ffmpeg → tsMuxer → ISO / BDMV`, расчёт битрейта и контроль размера.
- `settings.py` — сохранение локальных настроек в `%APPDATA%\DiscForgeRU\settings.json`.
- `tests/` — тесты core (не требуют UI-библиотеки).
- `.github/workflows/` — CI unit tests и экспериментальная сборка Windows.
- `docs/ROADMAP.md` — этапы достижения истинного Blu-ray авторинга с меню.

Один файл обычно становится **одним диском**, а не несколькими фильмами на общем диске. Видеоряд преобразуется в 1080p/23.976 fps, возможен judder. HDR-исходники блокируются, чтобы не получить некорректные цвета без UHD-пайплайна.

## Почему меню — отдельный проектный этап

`tsMuxer` умеет создавать Blu-ray-плейлисты, главы и BDMV, но **не генерирует полноценную интерактивную навигацию**. Для настоящих меню нужно создать BD-J Xlet и дисковые BDJO/JAR/BDMV структуры или реализовать авторинг HDMV Interactive Graphics. Это нетривиальный самостоятельный модуль. Возможные открытые проекты для изучения: [HD Cookbook](https://github.com/enteractive-dev/hdcookbook), [auto-bluray-tui](https://github.com/cheeseb1234/auto-bluray-tui) (BD-J/GRIN по заявлениям авторов). Технические, лицензионные и совместимые с Windows варианты интеграции ещё необходимо исследовать и тестировать.

## Безопасность и ограничения

- Нет доступа к DRM, AACS, ключам, взлому/снятию защиты, загрузке фильмов.
- Запуск внешних инструментов происходит **аргументами**, без `shell=True`.
- Папки готовых выходных файлов не перезаписываются: новая версия получает суффикс `_2`.
- Промежуточные файлы удаляются после завершения/ошибки; оставляйте достаточно места для временного кодирования.
- Контроль размера проводится после сборки. Расчёт битрейта — оценка и не гарантирует вместимость.
- **Изготовленный ISO/BDMV не считается подтверждённо совместимым с плеером до физического тестирования.**
